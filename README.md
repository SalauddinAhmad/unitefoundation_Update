## 🕌 পরিচিতি (About)

**Unite Foundation** হচ্ছে একটি পূর্ণাঙ্গ ওয়েব প্ল্যাটফর্ম, যেখান থেকে ফাউন্ডেশনের সকল কার্যক্রম — দাওয়াহ, শিক্ষা, দাতব্য প্রকল্প, স্বেচ্ছাসেবক ব্যবস্থাপনা, ব্লগ ও গ্যালারি — একটি কেন্দ্রীয় ড্যাশবোর্ডের মাধ্যমে পরিচালনা করা যায়।

সাইটটি সম্পূর্ণ **বাংলা (বাংলা ভাষা)** কনটেন্টে তৈরি এবং মোবাইল-ফার্স্ট ডিজাইনে অপ্টিমাইজড।

## ✨ প্রধান ফিচার (Features)

### পাবলিক ওয়েবসাইট
- 🏠 **হোমপেজ** — হিরো সেকশন, নামাজের সময়সূচি (Adhan), প্রকল্প প্রদর্শনী, ইমপ্যাক্ট পরিসংখ্যান, পার্টনার ও ভিজিটর কাউন্টার
- 📿 **রিয়েল-টাইম নামাজের সময়** — হিজরি ক্যালেন্ডার সহ (`adhan` লাইব্রেরি)
- 📚 **ব্লগ সিস্টেম** — রিয়েল ভিউ কাউন্টার, লেখক বাইলাইন, শেয়ার
- 🖼️ **গ্যালারি** — ইমেজ + YouTube ভিডিও (অটো থাম্বনেইল, লাইটবক্স প্লেয়ার)
- 🤝 **প্রকল্পসমূহ** — চলমান/সম্পন্ন স্ট্যাটাস, উপকারভোগী ও দাতা সংখ্যা, সময়সূচি
- 💰 **ডোনেশন পেজ** — মোবাইল ব্যাংকিং (bKash, Nagad, Rocket), ব্যাংক অ্যাকাউন্ট, QR কোড; নিয়মিত/মাসিক/আজীবন দাতা ক্যাটাগরি
- 📝 **ডাইনামিক ফর্ম** — স্বেচ্ছাসেবক ও সদস্য নিবন্ধন (ডিসপোজেবল ইমেইল ব্লকিং সহ)
- 👥 **টিম পেজ** — উপদেষ্টা ও দায়িত্বশীল, প্রতিষ্ঠাতা/চেয়ারম্যান প্রোফাইল
- 📄 **নীতিমালা পেজ** — Privacy, Terms, Refund Policy
- 🔍 **SEO অপ্টিমাইজড** — মেটা ট্যাগ, Open Graph, স্লাগ-বেজড রাউটিং

### অ্যাডমিন ড্যাশবোর্ড
- 🔐 **সুরক্ষিত অথেনটিকেশন** — JWT + role-based access
- 📊 **ওভারভিউ** — সাবমিশন, ডোনার, ভিজিটর অ্যানালিটিক্স
- 📝 **কনটেন্ট ম্যানেজমেন্ট** — ব্লগ, প্রকল্প (drag-to-reorder), গ্যালারি, টিম, পার্টনার
- 🎨 **সাইট সেটিংস** — পেজ হেডার ব্যানার, পেমেন্ট অ্যাকাউন্ট + QR, ইমপ্যাক্ট স্ট্যাটস
- 🛠️ **ডাইনামিক ফর্ম বিল্ডার** — সাইড-কনটেন্ট/ব্যানার সহ
- 📧 **ইমেইল সিস্টেম** — কাস্টম HTML টেমপ্লেট এডিটর, নিউজলেটার ব্রডকাস্ট
- 📸 **মিডিয়া লাইব্রেরি** — WebP অটো কম্প্রেশন, স্মার্ট ফাইল নেমিং
- 📜 **অ্যাক্টিভিটি লগ** — লগইন, পোস্ট create/edit/delete ট্র্যাকিং

## 🛠 টেকনোলজি স্ট্যাক (Tech Stack)

**Frontend**
- React 18 · TypeScript 5 · Vite 5
- Tailwind CSS 3 · shadcn/ui · Radix UI
- React Router v6 · TanStack Query · React Hook Form + Zod
- i18next (বাংলা) · Lucide Icons · Recharts

**Backend**
- Node.js · Express
- MySQL / MariaDB (cPanel-hosted)
- JWT authentication · bcrypt

**Deployment**
- cPanel shared hosting (Node.js app + static frontend)

## 🚀 লোকাল ডেভেলপমেন্ট (Getting Started)

### Prerequisites
- Node.js ≥ 18
- MySQL / MariaDB
- npm / bun / pnpm

### Setup

```bash
# 1. রিপোজিটরি ক্লোন
git clone https://github.com/<your-org>/unite-foundation.git
cd unite-foundation

# 2. Frontend ডিপেন্ডেন্সি
npm install

# 3. Backend ডিপেন্ডেন্সি
cd server && npm install && cd ..

# 4. এনভায়রনমেন্ট ভেরিয়েবল
cp server/.env.example server/.env
# .env ফাইলে DB, JWT_SECRET, SMTP সেট করুন

# 5. মাইগ্রেশন রান
cd server && npm run migrate && cd ..

# 6. ডেভ সার্ভার চালু
npm run dev            # Frontend → http://localhost:8080
cd server && npm start # Backend  → http://localhost:3000
```

### Environment Variables

| Variable | Description |
|---------|-------------|
| `DB_HOST` / `DB_USER` / `DB_PASSWORD` / `DB_NAME` | MySQL কানেকশন |
| `JWT_SECRET` | টোকেন সাইনিং কী |
| `SMTP_HOST` / `SMTP_USER` / `SMTP_PASS` | ইমেইল পাঠানোর জন্য |
| `CORS_ORIGIN` | অনুমোদিত ফ্রন্টএন্ড ডোমেইন |

## 🌐 ডিপ্লয়মেন্ট (Deployment)

1. **Frontend** — `npm run build` → `dist/` ফোল্ডার cPanel-এর `public_html/` এ আপলোড
2. **Backend** — `server/` ডিরেক্টরি cPanel-এর Node.js app হিসেবে সেটআপ; entry point: `app.js`
3. **Database** — নতুন মাইগ্রেশন থাকলে cPanel phpMyAdmin থেকে রান করুন
4. **Environment** — cPanel-এর Node.js app কনফিগ থেকে env variable সেট করুন
